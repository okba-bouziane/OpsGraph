# Decision: Run Redis on a single host
*Sample data, fictional.*

Document ID: ADR-001
Type: Decision
Date: 2024-02-10
Status: Superseded by ADR-002
Applies to: SVC-REDIS

## Context
In early 2024 Redis only cached pages. Losing it meant slower pages, not lost data.

## Decision
Run Redis on one host with 16 GB of memory, restarted by hand when needed.
