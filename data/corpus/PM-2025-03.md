# Postmortem: Carts lost during the Ramadan sale
*Sample data, fictional.*

Document ID: PM-2025-03
Type: Postmortem
Date: 2025-03-14
Severity: SEV1
Root cause: SVC-REDIS
Impacted: SVC-CHECKOUT; SVC-STOREFRONT
Follow-ups: ADR-002; RB-REDIS-FAILOVER
Duration: 47 minutes

## Summary
During the first evening of the Ramadan sale, the single Redis host ran out of memory and stopped accepting writes. Customers lost their carts and checkout failed for 47 minutes. About 3,100 orders were not placed.

## Root cause
The page cache had no expiry on some keys and filled the 16 GB of memory. Redis ran on one host, so there was nothing to fail over to.

## Action items
- TEAM-PLATFORM will run Redis with a replica and Sentinel by 2025-04-30.
- TEAM-DISCOVERY will set a 60-second expiry on every page cache key by 2025-03-31.
- TEAM-PAY will show a clear message instead of an empty cart when Redis fails by 2025-04-15.
