# Decision: Redis with a replica and Sentinel
*Sample data, fictional.*

Document ID: ADR-002
Type: Decision
Date: 2025-04-02
Status: Accepted
Applies to: SVC-REDIS; SVC-CHECKOUT
Supersedes: ADR-001
References: PM-2025-03

## Context
Carts moved into Redis in late 2024, so losing Redis now loses customer data. The Ramadan sale outage showed that a single host is not acceptable.

## Decision
Run Redis as a primary with one replica in a second rack, and Redis Sentinel with three voters to promote the replica automatically. Failover should take under 30 seconds.

## Consequences
Memory cost doubles. The old restart runbook is replaced by RB-REDIS-FAILOVER.
