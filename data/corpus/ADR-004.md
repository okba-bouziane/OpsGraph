# Decision: PgBouncer in front of main-db
*Sample data, fictional.*

Document ID: ADR-004
Type: Decision
Date: 2025-10-09
Status: Accepted
Applies to: SVC-MAINDB; SVC-ORDERS; SVC-CATALOG; SVC-PAYMENTS
References: PM-2025-10

## Context
Services opened direct connections to the primary and a single import exhausted the 400-connection limit.

## Decision
All services connect through PgBouncer in transaction mode. Each service gets a fixed pool: orders-service 40, catalog-service 30, payments-gateway 20, imports 10.

## Consequences
Session-level features such as prepared statements across transactions are no longer available.
